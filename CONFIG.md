# Scrap Pickup settings

Settings live in `BepInEx\config\com.dev.survivallog.scrappickup.cfg`, created the first time the game starts with the mod. Change them in game on the Mod Manager's Mods screen, where they take effect at once, or edit the file while the game is closed. Delete the file to get the defaults back. Without Exiled's Toolkit installed, changes made on the Mods screen take effect at the next game start instead.

## Scrap

| Setting | Default | What it does |
| --- | --- | --- |
| `ToTrunk` | `true` | While exploring, items from furniture you scrap or demolish go to your trunk or shopping cart first, then your backpack. Set it to `false` to skip the trunk; items then go to your backpack. At home the trunk is never used. Items drop on the ground only when nothing has room. |
